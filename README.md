# VirusCheck

Cek virus file — 100% Buatan Raka!

## Fitur

- **Cek Offline Instan** — Analisis 16 langkah tanpa internet:
  - Analisis nama & ekstensi file
  - Hash SHA-256
  - Analisis izin APK (berbahaya vs normal)
  - Deteksi pola spyware, ransomware, banker
  - Deteksi intersepsi SMS, auto-start, aplikasi palsu
  - Deteksi packer/obfuscator & API berbahaya
  - Pindai URL & IP mencurigakan
- **Penjelasan sederhana** — Tiap temuan dijelasin kenapa bahayanya (Bahasa Indonesia!)
- **Riwayat** — Simpan semua hasil pemeriksaan
- **Pengaturan lengkap** — Tema terang/gelap, warna aksen & latar custom, ukuran font, sensitivitas, mode ketat
- **Tanpa emoji** — Semua ikon SVG profesional
